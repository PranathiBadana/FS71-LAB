# Node.js Built-in Modules

## Aim

To implement and demonstrate the use of built-in modules in Node.js.

## Modules Used

1. **OS Module** – Used to obtain information about the operating system and computer.
2. **Path Module** – Used to work with file and directory paths.
3. **DNS Module** – Used to resolve domain names into IP addresses.
4. **Net Module** – Used to create a TCP server and handle network connections.

## Technologies Used

* Node.js
* JavaScript
* VS Code

## How to Run

1. Open the project folder in VS Code.
2. Open the terminal.
3. Run:

```bash
node app.js
```

4. The program displays information from the OS, Path, and DNS modules.
5. It also starts a TCP server on port 3000.
6. Press `Ctrl + C` to stop the server.

## Conclusion

The OS, Path, DNS, and Net built-in modules were successfully implemented in Node.js. The program demonstrates how Node.js can interact with the operating system, file paths, DNS services, and network connections.
